# MCAS-ICT

ICT Asset Management System for Mutare City Council — Web + PWA app.

## Structure

```
├── frontend/   React + Vite + TypeScript + Tailwind CSS + PWA
├── backend/    Node.js + Express + TypeScript
└── docs/
```

## Getting started

```
npm install
npm run dev:backend    # backend dev server (http://localhost:4000)
npm run dev:frontend   # frontend dev server (http://localhost:5173)
```

## Scripts

- `npm run build:frontend` / `npm run build:backend`
- `npm run lint`, `npm run format`

See `01_project_overview.txt` for the architecture and design documents.
